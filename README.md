# ORBITAL/01 — Le verger des étoiles

Un site immersif et interactif autour d'une rencontre imaginaire entre l'espace et les abricots.

## Contenu
- Expérience éditoriale à défilement, univers cosmique et navigation responsive.
- Système planétaire interactif avec fiches de données.
- Verger imaginaire : quatre fruits cliquables avec micro-récits.
- Console de contrôle : vitesse orbitale, densité stellaire et mode comètes.
- Lecteur vidéo HTML5 avec contrôles natifs et affiche NASA.
- Animations avec prise en compte de `prefers-reduced-motion`.

## Mise en ligne (GitHub Pages)
Le dépôt contient un workflow GitHub Actions dans `.github/workflows/pages.yml`. Dans GitHub : **Settings → Pages → Build and deployment → Source: GitHub Actions** si nécessaire.
Le site est servi depuis la racine du dépôt.

## Note éditoriale
Abricot-7, le verger spatial et les spécimens fruitiers sont fictifs. Les faits concernant Mercure, Vénus, Mars et Jupiter sont des résumés pédagogiques de données astronomiques publiques.
